# 仕様データの出典と確認状況 / Spec sources

このデモの仕様値はすべて、参考資料として提供された市販のエアーモーター撹拌機カタログ（PDF、非公開・本リポジトリには含めない）から転記しています。
モデル名・型番（AXIS 08 / 10 / 15、NXM-…）はデモ用の架空名称です。元製品の型番との対応表はリポジトリ外で管理しています。

## 採用モデルと選定理由

| デモ名 | カタログ頁 | 分類 | 選定理由 |
|---|---|---|---|
| AXIS 08 | p.07–08 | 減速機付き撹拌機 | 小容量・アーム式。φ8 シャフト / 4枚プロペラ φ50 / ドリルチャック |
| AXIS 10 | p.09–10 | 減速機付き撹拌機 | 中容量。アーム・クランプ・ヘルール・フランジの4取付に対応 |
| AXIS 15 | p.11–12 | 減速機付き撹拌機 | 100〜200 L クラス。φ15 シャフト / セットボルト固定 |

3機種は同じ構成（エアーモーター → タイミングベルト式減速機 → シャフト → プロペラ）で、仕様欄・寸法図・参考回転数表（0.3 / 0.6 MPa）がそろっているため、同条件での比較が成立します。

## カタログで確認できた項目（CATALOG）

- 最大エアー圧力 0.63 MPa、最大エアー消費量（240 / 318 / 486 L/min）
- モータータイプ別の 出力 kW・トルク N·m・最大出力時回転数・自由回転数
- 参考回転数（無負荷・シャフト/プロペラ無し）と その時のエアー消費量（0.3 / 0.6 MPa）
- シャフト φ×長さ、プロペラ枚数と径、標準材質 SUS304
- シャフト固定方式（キーレスドリルチャック / セットボルト 2-M6）、標準スタンド形式（U / V2 / H2）
- 寸法図（アーム式）：本体高さ、配管部参考寸法、減速機上面高さ、軸芯〜減速機端、アーム全長・径
- 用途アイコン（混合・沈降防止・高粘度・分散・乳化）、取付方法、シャフト固定方法、液量バー
- シリーズ共通：圧縮空気駆動、タイミングベルト式でオイル不要、供給圧 0.3〜0.63 MPa、レギュレーターで速度調整、サイレンサーから排気

## カタログで確認できなかった項目（NO DATA）

重量 / 回転方向 / 減速比・プーリー径 / スタンド支柱高さ・ベース寸法 / プロペラのピッチ角・断面形状 / エアーモーター内部構造

## 3Dモデルの再現範囲

| 区分 | 内容 |
|---|---|
| DRAWING | 減速機ハウジングの幅、モーター軸の位置、モーター各段の径と高さ、アーム位置：寸法図を記載寸法で縮尺換算 |
| CATALOG | シャフト径・長さ、プロペラ径・枚数、本体高さ、アーム長さ・径 |
| CONCEPT | ハウジング奥行き、プロペラ羽根形状、サイレンサー・透明ボウルの配置、スタンド、減速機内部（プーリー・ベルト）、動力伝達ライン |
| DEMO | アニメーションのスロー倍率、回転方向（CW/CCW）切替 |
